# Лабораторная работа 1 — вариант 9

Группа 507, Демидович В.А., номер по списку 6. Меню столовой на 5 дней, 15 блюд.

## Установка и запуск

Проверено на Python 3.13.3, NumPy 2.3.5, SciPy 1.18.1. HiGHS 1.12.0 включён в установленный SciPy, отдельно устанавливать его не нужно.

```sh
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python main.py
```

В Windows вместо команды активации используется `.venv\Scripts\activate`.
После установки весь расчёт запускается одной командой `python main.py` из папки работы. Пути внутри программы определяются относительно main.py, поэтому допустим запуск из другой папки. Выполняются три сценария, проверки и локальные эксперименты с теневыми ценами. Сводка выводится на экран, подробности сохраняются в results/.

## Файлы

- REPORT.md — отчёт, математическая модель, результаты и подготовка к защите.
- data/dishes.csv — состав и цена условной порции каждого блюда.
- data/config.json — вариант, нормы и параметры сценариев.
- generate_data.py — генератор данных с seed=10006. Для повторной генерации: `python generate_data.py`. Он перезаписывает только два файла данных.
- main.py — загрузка, построение модели, решение, независимая проверка и экспорт.
- results/*_solver.log — настоящие логи HiGHS.
- results/*_solution.csv — все 75 переменных, включая нулевые.
- results/*_constraints.csv — все 41 ограничение, запас и двойственная оценка преобразованной правой части. Границы 0≤x≤3 проверяются отдельно.
- results/*_verification.json — результаты проверок или сертификат несовместимости.
- results/*_sensitivity.csv — изменение активных ограничений на 0.001 и сравнение с прогнозом.
- results/scenarios.csv — итоговое сравнение сценариев.
- results/environment.json — версии использованного окружения.

Для infeasible-сценария таблицы решения нет: допустимый план не существует. Графики для ЛР 1 методичкой не предписаны; сравнительная таблица приведена в отчёте и CSV.

Все сведения о питании и ценах — синтетические учебные данные. Нормы описывают условный суточный рацион одного посетителя, а не клиническую рекомендацию. При изменении данных нужно заново обновить содержательные выводы REPORT.md.

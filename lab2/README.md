# Лабораторная работа 2 — вариант 9

Группа 507, Демидович В.А., номер по списку 6. Два груза с общей пропускной способностью: 10 узлов, 20 дуг, seed=10006.

## Установка

Проверено на Python 3.13.3. Версии NumPy, SciPy и Matplotlib закреплены в requirements.txt. HiGHS 1.12.0 входит в SciPy и отдельно не устанавливается.

```sh
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

В Windows активация: `.venv\Scripts\activate`.

## Запуск

```sh
python main.py
```

Запускать из папки работы. Программа также поддерживает вызов из другой папки: пути к данным определяются относительно main.py. Выполняются базовый сценарий, снижение мощности самой загруженной дуги на 20%, рост спроса на 20% и закрытие самой загруженной дуги. Дуга выбирается по суммарному потоку базового решения; при равенстве — по меньшему номеру. Генерация данных не требуется для обычного запуска.

## Файлы

- REPORT.pdf — отчёт для сдачи со схемами четырёх сценариев.
- REPORT.md — текст отчёта; схемы находятся в results/.
- DEFENSE.md — отдельные заметки для защиты.
- main.py — модель, решатель, проверка, эвристика и схемы (Matplotlib, без NetworkX).
- generate_data.py — генератор, повторный запуск `python generate_data.py` воспроизводит и перезаписывает только данные.
- data/arcs.csv — топология, общая мощность и два тарифа каждой дуги.
- data/config.json — параметры варианта, источники, получатели и спросы.
- results/*_solver.log — фактические логи HiGHS.
- results/*_flows.csv — потоки обоих грузов по всем дугам, запас мощности, насыщение и теневая цена.
- results/*_balances.csv — независимая проверка каждой пары груз/узел.
- results/*_summary.json — статус и проверка, время, стоимость и эвристика.
- results/*_greedy_flows.csv — допустимые планы эвристики.
- results/*_sensitivity.csv — изменение мощности каждой насыщенной дуги на ±0.001 и повторное решение.
- results/*_network.png — схема сети с потоками A/B и общей мощностью, т/сут.
- results/scenarios.csv — сравнение сценариев и эвристики.
- results/environment.json — версии окружения; версия HiGHS находится в логах.

Все данные синтетические; расходы выражены в условных денежных единицах. Денежная единица, общий временной интервал и допущения указаны в отчёте. При изменении данных следует пересчитать модель и обновить отчёт. Время в отчёте относится к одному фактическому запуску и при повторении меняется.
